# PDF 문서 서명

코드 이름은 **각인**(gakin)입니다. 웹 버전 주소: <https://dotori-forest.github.io/gakin/> (GitHub Pages를 켠 뒤 열립니다). Chrome·Edge 같은 Chromium 계열 브라우저에서 시험했습니다.

미리 그려 둔 서명을 PDF에 찍고, 스캔본처럼 **편집할 수 없는 PDF**로 저장합니다. 출력하고 스캔하는 과정을 대신합니다.

같은 코드로 두 가지 버전을 제공합니다.

| 버전 | 사용 방법 | 서명 저장 위치 |
| --- | --- | --- |
| Chrome 확장 프로그램 | 도구 모음 아이콘을 눌러 새 탭에서 사용 | `chrome.storage.local` |
| 웹 버전(GitHub Pages) | 설치 없이 주소로 접속 | 해당 사이트의 localStorage |

두 버전 모두 파일을 서버로 보내지 않습니다. 왼쪽 아래 **서명 백업**의 **백업**으로 서명을 JSON 파일로 내보내고 다른 버전·다른 PC에서 **불러오기**로 옮길 수 있습니다.

- **서명은 한 번만 그립니다.** 마우스로 그린 획은 서명 도구처럼 부드럽게 보정되고(떨림 제거, 속도에 따른 굵기 변화, 획 끝 가늘어짐), 이 브라우저에 저장됩니다. 다음부터는 고르고 클릭만 하면 됩니다.
- **이름으로도 만들 수 있습니다.** 이름을 쓰고 손글씨 글꼴 4종(나눔손글씨 펜·붓, 동해 독도, 개구) 중에서 고르면 서명이 됩니다. 글꼴은 패키지에 들어 있어 네트워크 없이 동작합니다. Windows PC에서는 PC에 설치된 굴림·돋움도 고를 수 있습니다(각인에 포함하지 않고 PC의 글꼴을 씁니다). 글꼴에 없는 글자가 이름에 있으면 그 글꼴은 고를 수 없게 표시합니다.
- **도장 이미지도 쓸 수 있습니다.** 흰 종이에 찍은 도장 사진을 불러오면 배경을 투명하게 만들어 저장합니다.
- **편집할 수 없게 저장합니다.** 각 쪽을 서명과 함께 하나의 그림으로 굳혀 PDF로 만듭니다. 글자 선택이나 서명 분리가 되지 않습니다.
- **이미지로도 저장합니다.** 저장 버튼 옆 ⋯에서 **PNG로 저장** 또는 **JPG로 저장**을 고르면 서명·글자·표시가 있는 쪽만 한 장씩 이미지로 저장합니다(아무것도 찍지 않았으면 모든 쪽, 여러 장이면 컴퓨터에서는 ZIP 하나로). PDF는 언제나 모든 쪽을 저장합니다. 휴대폰·태블릿에서는 이미지(PNG) 저장이 기본이고, 공유 창이 열려 사진에 저장하거나 메신저로 바로 보낼 수 있습니다. 컴퓨터에서는 ⋯에 마우스를 올리기만 해도 메뉴가 열립니다.
- **파일이 밖으로 나가지 않습니다.** 서버·계정·네트워크 요청이 없고, 모든 처리가 브라우저 안에서 끝납니다.

> 이 도구로 찍은 서명은 전자서명법에 따른 인증서 기반 전자서명이 아니며, 법적 효력을 보장하지 않습니다.

## 사용법

1. 도구 모음의 PDF 문서 서명 아이콘을 누르면 서명 화면이 새 탭으로 열립니다.
2. 처음에는 **서명 그리기**로 서명을 저장합니다. 여러 개(최대 12개)를 저장할 수 있습니다.
3. PDF, 한글(HWP·HWPX), 이미지(PNG·JPG·WebP)를 끌어다 놓거나 **파일 열기**로 엽니다. 다 쓴 문서는 파일 이름 옆 ✕로 닫습니다. 문서 오른쪽 아래 확대·축소 도구나 Ctrl+마우스 휠로 크기를 바꿉니다. 도구가 문서를 가리면 왼쪽 손잡이(⠿)를 끌어 옮깁니다.
4. 왼쪽에서 서명을 고르고 문서에서 서명할 곳을 클릭합니다. Shift를 누른 채 클릭하면 여러 번 찍을 수 있습니다.
5. 찍은 서명은 끌어서 옮기고, 오른쪽 아래 점으로 크기를 바꾸고, 위쪽 둥근 손잡이로 돌립니다(직각 근처에서 맞춰지고, Shift를 누르면 15°씩). 방향키로 미세 조정, R / Shift+R로 15°씩 회전, Delete로 삭제합니다. 바꾼 크기는 다음에도 기억합니다.
6. 왼쪽 아래(설정 바로 위) 아이콘 버튼으로 글자와 표시도 넣습니다. 버튼을 누르고 문서를 클릭하면 그 자리에 들어갑니다.
   - **글자**: 입력칸이 열립니다. Enter로 줄을 바꾸고, Esc나 다른 곳 클릭으로 마칩니다. 다시 고치려면 두 번 클릭(휴대폰은 선택한 뒤 한 번 더 누르기)하거나 선택하고 Enter를 누릅니다. 비워 두면 사라집니다.
   - **날짜**: 오늘 날짜를 `2026. 11. 20.` 형식으로 넣습니다. **이름**: 이름으로 만들기에서 쓴 이름을 넣습니다.
   - **체크·동그라미·엑스**: 선으로 그린 표시입니다. 동그라미는 원으로 들어가고, Shift를 누른 채 크기를 바꾸면 긴 낱말을 감싸는 타원으로 늘어납니다.
   - 서명처럼 옮기고, 크기를 바꾸고(글자는 크기에 맞춰 커집니다), 돌리고, 지웁니다. 저장하면 서명과 함께 쪽 그림에 합쳐집니다.
7. 찍기·글자 고치기·옮기기·크기·회전·삭제는 Ctrl+Z로 되돌리고 Ctrl+Shift+Z(또는 Ctrl+Y)로 다시 실행합니다. 문서 오른쪽 아래 도구 막대의 화살표 버튼도 같습니다.
8. **PDF로 저장**을 누르면 `원본이름_서명.pdf`가 내려받아집니다. 왼쪽 아래 **저장 화질**에서 낮음(150dpi)·보통(200dpi, 기본)·고화질(300dpi) 중에서 고릅니다. 낮을수록 파일이 작습니다.

휴대폰·태블릿에서도 웹 버전을 쓸 수 있습니다. 화면이 좁으면 서명 목록이 아래쪽 막대로 옮겨 가고 설정은 톱니바퀴 버튼 뒤에 접힙니다. 서명할 곳을 손가락으로 톡 누르면 찍히고(스크롤은 찍지 않습니다), 두 손가락으로 벌리거나 오므려 확대·축소합니다.

한글(HWP·HWPX) 문서는 [rhwp](https://github.com/edwardkim/rhwp)(Rust + WebAssembly)로 브라우저 안에서 직접 그립니다. 한글 파일을 처음 열 때 엔진(약 27MB)을 한 번 불러오므로 몇 초 걸릴 수 있습니다. 쪽 배치나 글꼴이 한컴오피스와 조금 다를 수 있으니, 정확한 모양이 중요하면 한글에서 **파일 → PDF로 저장**한 PDF를 여세요. DRM이 걸린 문서는 열 수 없습니다.

암호가 걸린 PDF와 한글 문서는 열 때 비밀번호를 묻습니다. 비밀번호는 문서를 여는 데만 쓰고 저장하지 않으며, 저장한 PDF에는 암호가 걸리지 않습니다. 한글은 HWP 5.0 이후 문서와 HWPX 문서의 암호를 지원하고, 오래된 HWP 3.0 일부 형식은 열 수 없습니다.

## 웹 버전 배포

`main` 브랜치에 올리면 `.github/workflows/pages.yml`이 먼저 `npm test`를 돌리고, 통과하면 `scripts/build-site.sh`로 `dist/site`를 만들어 GitHub Pages에 배포합니다. 풀 리퀘스트에서는 테스트만 돌립니다. 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 합니다. 로컬에서는 `npm run build:site`로 같은 결과를 만들 수 있습니다.

웹 버전은 확장 프로그램의 `editor.html`을 `index.html`로 그대로 사용하며, 확장 전용 파일(`manifest.json`, `src/background.js`)만 빠집니다. 페이지의 콘텐츠 보안 정책이 다른 주소로의 연결을 막습니다. 개인정보처리방침은 `privacy.html`로 함께 게시되어 웹스토어 등록 때 이 주소를 쓸 수 있습니다.

## 확장 프로그램 설치 (개발 중)

1. Chrome 116 이상에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**에서 이 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
3. 도구 모음의 퍼즐 아이콘에서 PDF 문서 서명을 고정하고 누르면 서명 화면이 새 탭으로 열립니다.
4. 코드를 고친 뒤에는 `chrome://extensions`에서 PDF 문서 서명 카드의 새로고침 버튼을 누르고 서명 화면 탭도 새로고침합니다.

빌드 과정은 없습니다. 웹스토어 제출용 ZIP은 `npm run package`로 만듭니다(`dist/gakin-<버전>.zip`). bash와 `zip` 명령이 필요합니다. Windows에서는 Git Bash에 zip이 없으니 WSL이나 macOS·Linux에서 실행하세요.

## 구조

| 파일 | 역할 |
| --- | --- |
| `editor.html`, `src/editor.js` | 서명 화면: 문서 표시, 찍기·이동·크기 조절, 저장 |
| `src/signaturePad.js` | 서명 입력판, 도장 이미지 배경 제거 |
| `src/strokes.js` | 획 보정(perfect-freehand)과 서명 데이터 정규화 |
| `src/documentSources.js` | PDF(pdf.js)·한글(rhwp)·이미지를 같은 쪽 단위 인터페이스로 제공 |
| `src/marks.js` | 글자·표시(체크·동그라미·엑스): 크기 재기와 그리기를 화면·저장에 똑같이 사용 |
| `src/exporter.js`, `src/pdfWriter.js` | 쪽마다 그림으로 굳혀 PDF로 묶기 |
| `src/signatureStore.js` | 서명 저장(확장: `chrome.storage.local`, 웹: localStorage) |
| `src/signatureBackup.js` | 서명 백업 파일 내보내기·검증해서 불러오기 |
| `src/nameSignature.js` | 이름으로 만들기: 글꼴 불러오기, 없는 글자 확인, 이름을 투명 PNG 서명으로 그리기 |
| `src/handwritingFonts.js`, `fonts/` | 손글씨 글꼴과 글꼴별 지원 글자 목록. `scripts/build-fonts.py`가 만듭니다 |
| `privacy.html` | 개인정보처리방침(웹 버전에 함께 게시) |

서명은 획의 좌표로 저장하고 찍을 때마다 다시 그리므로, 어느 화질로 저장해도 서명이 선명합니다.

화면의 아이콘은 모두 [Lucide](https://lucide.dev)를 씁니다. 아이콘은 Lucide(lucide-static 1.75.0, ISC)에서 경로를 그대로 가져와 `vendor/lucide/icons.js`에 넣었고, 라이선스는 `vendor/lucide/LICENSE`와 `THIRD_PARTY_NOTICES.txt`에 있습니다. 상단의 서명 마크(`icons/mark.png`)만 각인 자체 아이콘입니다.

## 테스트

Playwright와 Chromium이 필요합니다. WebKit(`npx playwright install webkit`)이 있으면 아이폰 Safari에서 서명 목록이 보이는지도 확인합니다(없으면 건너뜁니다). 출력 PDF 검사에는 `pdfinfo`·`pdftotext`(poppler-utils)를 사용합니다.

처음 한 번 설치합니다.

```bash
npm install
npx playwright install chromium
```

```bash
npm test
npm run test:extension
```

`npm test`는 개발 폴더와 웹 버전 빌드(`--site`)를 차례로 검사합니다. `tests/e2e.cjs`는 서명을 그려 저장하고, 백업을 내보낸 뒤 저장소를 비우고 다시 불러오며, PDF에 찍어 옮기고 크기를 바꾼 뒤 저장해 쪽 수와 텍스트 층이 없는지 확인합니다. `tests/name.cjs`는 이름으로 만들기에서 글꼴 4종이 불러와지고, 글꼴에 없는 글자가 있으면 그 글꼴을 막으며, 만든 서명을 찍어 PDF로 저장하는지 확인합니다. `tests/close.cjs`는 문서를 닫을 때 저장하지 않은 서명이 있으면 확인을 묻고, 닫은 뒤 처음 화면으로 돌아가는지 확인합니다. `npm run test:extension`은 개발자 모드처럼 이 폴더를 확장 프로그램으로 불러와 PDF를 열고 오류 없이 저장되는지 확인합니다. 시험할 PDF를 직접 주려면 `node tests/extension.cjs <pdf>`로 실행합니다.

## 손글씨 글꼴 다시 만들기

글꼴을 바꾸거나 추가할 때만 필요합니다. [google/fonts](https://github.com/google/fonts/tree/main/ofl)의 `ofl/` 폴더(원본 TTF와 `OFL.txt`)를 받아 두고 fonttools로 실행합니다.

```bash
pip install fonttools brotli
python scripts/build-fonts.py <ofl 폴더가 있는 경로>
```

예약된 글꼴 이름(Reserved Font Name)이 있는 나눔 글꼴은 수정하지 않고 그대로 복사하고, 나머지는 영문·한글만 남겨 WOFF2로 줄입니다.
