# Chrome 웹스토어 등록 준비

## 계정과 비용

- Chrome Web Store 개발자 등록: 1회 등록비 5달러, Google 계정 필요.
- 개인정보처리방침 URL: 웹 버전과 함께 게시되는 `https://dotori-forest.github.io/gakin/privacy.html`을 입력합니다(Pages를 켠 뒤).

## 패키지

```bash
npm run package
```

`dist/gakin-<버전>.zip`이 만들어집니다. 테스트·문서 파일은 포함하지 않습니다. 새 버전을 올릴 때는 `manifest.json`의 `version`을 올립니다.

## 등록 정보 초안

- 이름: PDF 문서 서명
- 요약(132자 이내): 미리 그려 둔 서명을 PDF에 찍고 편집할 수 없는 PDF로 저장합니다. 파일은 외부로 전송되지 않습니다.
- 카테고리: 생산성(Productivity)
- 언어: 한국어

설명:

> 출력하고, 서명하고, 스캔하는 일을 클릭 몇 번으로 끝냅니다.
>
> • 서명은 한 번만 그리세요. 마우스로 그려도 서명 도구처럼 부드럽게 보정됩니다.
> • 이름을 쓰고 손글씨 글꼴을 고르면 바로 서명이 됩니다.
> • 도장 사진을 불러오면 배경을 지워 도장으로 쓸 수 있습니다.
> • PDF뿐 아니라 한글(HWP·HWPX) 문서와 이미지도 바로 엽니다.
> • 문서에서 서명할 곳을 클릭하면 찍힙니다. 옮기고 크기를 바꿀 수 있습니다.
> • 스캔본처럼 편집할 수 없는 PDF로 저장합니다.
> • 문서와 서명은 컴퓨터 밖으로 나가지 않습니다. 계정도 서버도 없습니다.
>
> ※ 전자서명법에 따른 인증서 기반 전자서명이 아니며, 법적 효력을 보장하지 않습니다.

## 심사 항목 답변

- **단일 목적**: 사용자가 저장해 둔 서명 이미지를 PDF·한글·이미지 문서에 배치하고, 평탄화된 PDF로 저장합니다.
- **storage 권한 사유**: 사용자가 만든 서명을 다음에 다시 쓸 수 있도록 로컬에 저장합니다.
- **원격 코드**: 사용하지 않습니다. 모든 스크립트와 WASM은 패키지에 포함되어 있습니다. `content_security_policy`의 `'wasm-unsafe-eval'`은 패키지에 든 WASM(PDF 이미지 디코더, 한글 문서 엔진 rhwp)을 실행하는 데만 필요합니다.
- **데이터 사용**: 어떤 사용자 데이터도 수집하거나 전송하지 않습니다(모든 항목 "수집 안 함").
