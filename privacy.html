PDF 문서 서명

개인정보처리방침

시행일: 2026-11-18 · 적용 대상: PDF 문서 서명(각인) Chrome 확장 프로그램과 웹 버전

PDF 문서 서명은 사용자의 개인정보를 수집하지 않습니다.

문서

사용자가 연 PDF·한글(HWP·HWPX)·이미지 파일은 브라우저 안에서만 처리하며, 어떤 서버로도 전송하지 않습니다. 화면을 닫으면 메모리에서 사라집니다. 웹 버전도 페이지 파일을 내려받은 뒤에는 모든 처리를 사용자의 브라우저에서 합니다.

서명

사용자가 그리거나 불러온 서명·도장 이미지는 사용자의 브라우저에만 저장됩니다. 확장 프로그램은 chrome.storage.local, 웹 버전은 해당 사이트의 브라우저 저장소(localStorage)를 사용합니다. 화면에서 직접 삭제하거나, 확장 프로그램을 제거하거나, 사이트 데이터를 지우면 사라집니다.

네트워크와 권한

이 프로그램은 외부로 데이터를 보내는 요청을 하지 않으며, 분석·광고·추적 도구를 사용하지 않습니다. 콘텐츠 보안 정책으로 다른 주소와의 연결을 막아 두었습니다. 확장 프로그램은 서명 보관용 storage 권한만 사용합니다.

웹 버전은 GitHub Pages가 호스팅합니다. 페이지를 내려받을 때 GitHub이 일반적인 웹 서버처럼 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다. 문서와 서명은 이 기록에 포함되지 않습니다.

서명의 효력

이 프로그램으로 찍은 서명은 전자서명법에 따른 인증서 기반 전자서명이 아니며, 법적 효력을 보장하지 않습니다. 문서를 받는 쪽이 요구하는 서명 방식을 확인해 주세요.
